# Practical 5: Creating tables of results in R

Practical materials for "Data Science for Geographers".

- `Practical_5_Presenting_regression_results.ipynb` is the practical notebook.
- `merged_data.csv` is the dataset created at the end of Practical 1.

Keep the notebook and `merged_data.csv` in the same folder. The practical writes four Word tables (`.docx`) and a coefficient plot (`.jpg`) to the same folder.

The data are simulated: every datazone and value is fictional.

The notebook needs `tidyverse`, `jtools`, `huxtable`, `IRdisplay`, `flextable`, `dotwhisker`, `table1`, `modelsummary` and an R Jupyter kernel. It installs these itself with `install.packages()`.
